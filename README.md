## Tecnologías

### Python

**Python** es un lenguaje de programación de alto nivel, interpretado y de propósito general. Se caracteriza por tener una sintaxis sencilla y legible, por lo que es utilizado para desarrollar aplicaciones, automatización, análisis de datos, inteligencia artificial y diferentes tipos de sistemas.

En este repositorio se utilizará Python como base para el aprendizaje y desarrollo de los proyectos de programación.

---

### Django

**Django** es un framework web desarrollado con Python que permite crear aplicaciones y sitios web de manera estructurada y eficiente.

Django proporciona herramientas para trabajar con bases de datos, usuarios, URLs, plantillas, formularios y otros componentes necesarios para desarrollar aplicaciones web.

---

### Odoo

**Odoo** es una plataforma empresarial de código abierto que permite desarrollar y administrar diferentes tipos de aplicaciones para una empresa.

Odoo utiliza Python principalmente para su lógica de negocio y permite trabajar con módulos que pueden ser desarrollados o personalizados según las necesidades de cada proyecto.
